# South Florida Dog Beaches (static site)

Unofficial, independent guide to dog beaches and off-leash dog parks in Miami-Dade, Broward and Palm Beach.

- `tools/places.json`: 23 records (7 beaches, 16 parks) with hours, fees, rules, official source URLs, conflict flags, and coordinates when a confident point was found.
- `tools/geo.json`: coordinates for the extra city dog parks listed by Broward County. Same rule: no guessed points.
- `tools/build.py`: generator, writes `site/`.
- BASE: https://south-florida-dog-beaches.vercel.app
